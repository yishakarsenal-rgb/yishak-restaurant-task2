Yishak Restaurant — Web Application

A modern, high-performance, and responsive web application built for **Yishak Restaurant**, celebrating authentic traditional Ethiopian cuisine with a seamless digital dining experience.

Features

- Dynamic Theme System: Seamless toggle between Light Mode and Dark Mode with persistent state via localStorage.
- Responsive Mobile Experience: Mobile-first layout adjustments including stackable section grids and full-width drawer navigation.
- Interactive Menu & Filtering:Categorized dish catalog featuring authentic main dishes, drinks, and specialty coffee, with dynamic category filter buttons.
- Active Shopping Cart: Real-time item count badge animations, expandable side drawer, and live price total calculation in ETB.
- Grid Media Gallery: Responsive gallery displaying restaurant moments, traditional coffee ceremonies, and high-resolution food photography.
- Table Reservation Interface: Clean reservation booking form for guests to reserve tables online.

Tech Stack

- Frontend:HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
- Scripting:JavaScript (Vanilla ES6+)
- Deployment:Vercel / GitHub Pages
